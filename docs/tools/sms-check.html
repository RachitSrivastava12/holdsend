SMS link check

This page checks the SMS hand-off links of HoldSend's emergency module on a real phone. It runs smsLink from @holdsend/core@0.2.0, the version on npm.

It sends nothing by itself. Every link only opens your messaging app with the text filled in; you can close it without sending. The numbers you type stay on this phone and are not saved.

The default text has an accented letter, an emoji, the characters & = + ? # and a line break, because those are the ones links break most often.

For each link: tap it, look, come back

  1. Did the messaging app open?
  2. Are the right recipients filled in?
  3. Is the text exactly the same as above, character for character?
