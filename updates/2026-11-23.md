## LinkedIn post
Today I found that the HoldSend docs site was missing half of its own design decisions. The site only publishes pages from a hand-kept list, and since early November nobody had added the new ones: eleven decision records and two audits were only on GitHub. Nothing was broken in a way a link checker would see, which is why it went unnoticed. The fix took two minutes. The useful part is the test that now fails when a decision or audit file is not on the list, so the final audit before 1.0 cannot be missed the same way. The lesson: any list a person has to remember to update needs a test that compares it with the folder it describes. https://github.com/zyakuhq/holdsend
