## LinkedIn post
Before this week, every check I ran before a HoldSend release loaded the packages straight from the repository. That is not what a user gets. A user gets a tarball from npm, and the first time I tested one was after the release was already approved. If a file was missing, the only fix was another version. So today I added a step that packs all four packages, installs them into an empty folder, and runs the same smoke test there, on the newest and the oldest Node we support. I broke the packaging on purpose twice to make sure it fails. The lesson: test the thing you ship, not the thing you build. https://github.com/zyakuhq/holdsend
