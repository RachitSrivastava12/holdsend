Moving three diagnostic fields under one name costs every user a single edit now; after 1.0 it would cost a major version. For the early drafts API I did not want a judgment call in January, so the rule is written down: it joins the 1.0 promise only if its recorded API does not change after 0.3.0 and the final audit finds nothing.
